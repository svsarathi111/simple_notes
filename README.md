# Sticky Notes — Mobile App

A lightweight, beautiful sticky-note app for iOS and Android.
Built with Capacitor (web tech wrapped as native), runs everywhere.

## What's included

- **3 independent notes** with separate storage
- **Undo/redo** on each note (with history stack)
- **Rich text**: bold, italic, underline, text color, fonts, sizes
- **Lists**: bulleted and numbered
- **Background colors**: 7 preset sticky-note colors + custom picker
- **Autosave** to device storage (survives app restart)
- **Haptic feedback** on iOS/Android (subtle button taps and saves)
- **Mobile UI**: optimized for touch, respects safe areas, notches

## Quick start

### For web testing (no build needed)
```bash
npm install
npm run dev
# Open http://localhost:8000
```

### For iOS
```bash
npm install
npm run sync
npm run open:ios
# Build in Xcode
```

### For Android
```bash
npm install
npm run sync
npm run open:android
# Build in Android Studio
```

See [SETUP.md](./SETUP.md) for detailed deployment instructions.

## Features in detail

**Text formatting**
- Font family (Sans, Serif, Mono, Comic Sans)
- Font size (S, M, L, XL)
- Bold, italic, underline
- Text color picker

**Lists**
- Bulleted (•) and numbered (1)
- Each note can mix lists and paragraphs
- Full undo/redo support

**Background colors**
- 7 preset sticky-note colors (cream, yellow, pink, teal, blue, purple, white)
- Custom color picker for any hex color
- Change color per-note

**Storage**
- Autosaves every 0.5s after you stop typing
- Saves to device localStorage (not synced to cloud)
- Last-saved timestamp shown in footer
- Visual "Saved" indicator after each save

**History**
- Undo/Redo for each note (separate stacks)
- Ctrl+Z / Ctrl+Shift+Z (Cmd+Z on Mac)
- Toolbar buttons
- Up to 100 steps per note

**Performance**
- Zero external dependencies (no frameworks)
- ~25KB total (CSS + JS)
- Instant startup
- Smooth scrolling on mobile
- Touch-optimized buttons (36px+ tap targets)

## Browser/device support

- **iOS**: 12+
- **Android**: 5.0+
- **Browsers**: Chrome, Firefox, Safari, Edge (modern versions)

## Storage

Notes are stored in the device's local storage:
- Each note gets its own key (`sticky-note-1`, `sticky-note-2`, etc.)
- Data is **private to the device** (not synced)
- Survives app restart, browser refresh
- Can be cleared via Settings → Safari/Chrome → Clear History

## Customization

Want more notes? Edit `www/app.js` and `www/index.html` to add entries to the notes array.

Want a different color? Modify `BG_PALETTE` in `www/notepad-widget.js`.

Want to disable haptics? Pass `useHaptics: false` when initializing the widget.

See [SETUP.md](./SETUP.md) for more customization options.

## Why Capacitor?

Capacitor lets you:
- Write once (HTML/CSS/JS)
- Deploy everywhere (iOS, Android, web)
- No native code needed (unless you want native plugins)
- Direct access to device APIs (camera, storage, haptics, etc.)
- Instant development feedback (reload in browser, then build to device)

This app runs the exact same code on iOS, Android, and the web. One codebase, multiple platforms.
