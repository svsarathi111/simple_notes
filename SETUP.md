# Sticky Notes Mobile App — Setup & Deployment

This is a **Capacitor-based app** — your web code (HTML/CSS/JS) runs natively on iOS and Android.

## Quick Start

### 1. Install dependencies

```bash
npm install
```

This installs Capacitor CLI and the necessary plugins (Haptics, Storage, App lifecycle).

### 2. Test in browser

```bash
npm run dev
```

Open `http://localhost:8000` in your browser to test the app locally.

### 3. Build for iOS

**Requirements:** Mac + Xcode 13+

```bash
npm run sync      # Copy web assets to iOS
npm run open:ios  # Opens Xcode
```

In Xcode:
1. Select **App** → **Any iOS Device (arm64)**
2. Product → Archive
3. Distribute App → App Store Connect
4. Follow the wizard to submit

**Or**, to run on a simulator:
- Select **App** → **iPhone 15 Pro (simulator)**
- Click the Play button

### 4. Build for Android

**Requirements:** Android Studio + SDK 21+

```bash
npm run sync        # Copy web assets
npm run open:android  # Opens Android Studio
```

In Android Studio:
1. Connect an Android phone or start the emulator
2. Click Run (Play button)
3. Approve the installation on your phone

**To submit to Google Play:**
- Build → Generate Signed Bundle/APK
- Follow the wizard (you'll need a signing key)
- Upload to Google Play Console

## Troubleshooting

### "npm: command not found"
Install Node.js from https://nodejs.org/

### "Xcode not found" (Mac)
Install Xcode from the App Store, then run:
```bash
sudo xcode-select --install
```

### "Android SDK not found"
Install Android Studio from https://developer.android.com/studio

### Notes not saving
Check that **localStorage** is enabled in the browser/app settings. On iOS, this is in Settings → Safari → Advanced → Offline Website Data.

### App crashing on startup
1. Check the browser console (Chrome DevTools on Android)
2. Verify `www/index.html` loads without errors
3. Ensure all script paths are correct

## Customization

### Change app name
Edit `capacitor.config.json`:
```json
{
  "appName": "My Sticky Notes"
}
```

### Change app icon
Replace `icon.png` in the native project (iOS: `ios/App/App/Assets.xcassets/AppIcon.appiconset/`, Android: `android/app/src/main/res/`)

### Add more notes
In `www/app.js`, add to the `notes` array:
```javascript
{
  id: "note4",
  storageKey: "sticky-note-4",
  title: "Shopping",
  defaultBg: "#ffd6e0"
}
```

And in `www/index.html`, add:
```html
<div id="note4"></div>
```

### Disable haptics
Pass `useHaptics: false` when creating a widget:
```javascript
new NotepadWidget(container, {
  useHaptics: false
});
```

## Publishing

### iOS App Store
1. Join Apple Developer Program ($99/year)
2. Create an app listing in App Store Connect
3. Generate a certificate + provisioning profile
4. Archive and upload from Xcode
5. Submit for review (takes 1–3 days)

### Google Play Store
1. Create a Google Play Developer account ($25 one-time)
2. Create an app listing in Google Play Console
3. Build a signed APK/AAB in Android Studio
4. Upload to Google Play Console
5. Submit for review (usually approved in hours)

## API & Customization

The widget is exposed globally as `NotepadWidget`. For advanced usage:

```javascript
// Get a note instance
const note = window.StickyNotesApp.getNote('note1');

// Public API
note.getText()           // Plain text
note.getHTML()           // Rich HTML
note.setHTML(html)       // Replace content
note.undo()              // Programmatic undo
note.redo()              // Programmatic redo
note.clear()             // Empty the note
note.destroy()           // Remove from DOM
```
